## ✦ Learning Roadmap

<details open>
<summary><strong>See my Blue Team roadmap</strong></summary>

<br>

### Phase 01 — Foundations
Security fundamentals, Linux, networking, logs, Blue Team basics.

### Phase 02 — Monitoring & Detection
Wireshark, IDS/IPS, Snort, Suricata, detection basics.

### Phase 03 — SIEM & Log Analysis
SIEM concepts, Splunk, Elastic, event correlation, dashboards.

### Phase 04 — Threat Intelligence & Vulnerabilities
Threat Intelligence, CVEs, EDR concepts, indicators of compromise.

### Phase 05 — Incident Response
Triage, containment, recovery, documentation, playbooks.

### Phase 06 — Digital Forensics
Memory analysis, Volatility, Autopsy, investigation basics.

### Phase 07 — Threat Hunting
MITRE ATT&CK, hunting concepts, detection reasoning.

### Phase 08 — Hardening & Defensive Architecture
Linux hardening, network hardening, Zero Trust, cloud basics.

### Phase 09 — Phishing, Malware & Ransomware
Phishing analysis, malware basics, ransomware awareness.

### Phase 10 — SOC Operations
Alert triage, monitoring workflow, investigation routines.

</details>
